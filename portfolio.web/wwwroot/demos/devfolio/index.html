Devfolio — the portfolio you are reading, with a CMS behind it.

Devfolio is a bilingual developer portfolio with a private admin area for projects, skills, experience, posts and messages. The public site is exported to plain static files and published on GitHub Pages, so it stays fast and free to host while the content lives in SQL Server.

How the export works

  • Render. The export controller requests the public pages server-side and rewrites links so the result can live in any subdirectory.
  • Collect assets. CSS, JavaScript, fonts, project images and the CV PDF are copied into a versioned package.
  • Package. The result downloads as a ZIP from the admin area — no build server or deployment credentials needed.
  • Publish. The ZIP is pushed to the gh-pages branch; GitHub Pages serves it at the custom project URL.
  • Iterate. Edit content in the admin app, export again, and the public site updates without a database in the request path.
