Implementation notes

  • Payment state machine. Provider webhooks are signature-checked and idempotent; refunds revoke entitlements in the same transaction.
  • Authorised playback. Every playback request checks entitlement and issues a short-lived token before the player can stream.
  • Server-side assessment rules. Quiz deadlines and attempt counts are enforced by the API, never by the browser.
  • Resumable uploads. Instructors upload video in chunks, so a dropped connection resumes instead of restarting.
  • Two database modes. SQLite for a zero-config demo, SQL Server through EF Core migrations for production.
  • Tested in CI. xUnit unit tests plus WebApplicationFactory integration flows: health, catalogue, register, login, checkout, webhook.
